Open-source CLI for KNXOpen-Source CLI für KNX

Your KNX installation, in plain text.Deine KNX-Installation, in Textform.

Start from scratch or import your ETS project. bussard keeps your KNX configuration in TOML files that you edit by hand or with your favorite LLM. It programs your devices, decodes the bus and keeps a history of every edit, so you can undo it.Starte ein neues Projekt oder importiere dein ETS-Projekt. bussard hält deine KNX-Konfiguration in TOML-Dateien, die du von Hand oder mit deinem LLM bearbeitest. Es programmiert deine Geräte, decodiert den Bus und speichert jede Änderung in einer Historie, damit du sie zurücknehmen kannst.

How it worksSo funktionierts

A KNX project, configured in TOML.KNX-Projekte, konfiguriert in TOML.

Everything bussard knows about your installation is stored in text files. Edit them in any editor, or let Claude / ChatGPT do it. Commands either write that config to devices or read the bus and explain it with the same config. Every edit can be undone.Alles, was bussard über dein Projekt weiß, ist in Text Dateien gespeichert. Bearbeite sie in einem beliebigen Editor oder lass das von Claude / ChatGPT erledigen. Mit Befehlen kannst du dann die Konfiguration auf die Geräte schreiben oder den Bus lesen. Jede Änderung lässt sich zurücknehmen.

One line per group address (groups.toml) and one file per device (devices/1.1.47.toml) including a table per channel. Keys and values come from the vendor's product data, so a channel reads like its page in ETS. Vendor ids and memory offsets live in the generated bussard.lock, which nobody edits.Die Gruppenadressen (groups.toml) und die Geräte (devices/*.toml) werden jeweils in einer Datei mit Tabellen für jeden Kanal konfiguriert. Die Keys und Werte stammen aus den Produktdaten des Herstellers, daher liest sich ein Kanal wie seine Seite in der ETS. Hersteller-IDs und Speicher-Offsets stehen im generierten bussard.lock, das niemand bearbeitet.

groups.toml
project = "Demo House"

groups = [
 {address="1/1/1", name="Hallway Light", dpt="1.001"},
 {address="1/1/7", name="Porch Light", dpt="1.001"},
 {address="1/1/8", name="Porch Status", dpt="1.001"},
 {address="3/0/0", name="Alarm", protected=true, dpt="1.005"},
]
devices/1.1.47.toml
address = "1.1.47"
name = "Switch actuator, 2-gang / blinds actuator, 1-gang"
product = "230021SU"

[location]
floor = "DG"
room = "Kind 2 Süd"

[channel.relaisausgaenge-1]
betriebsart = "Lüftungsklappe / Dachfenster"
langzeitbetrieb.listen = ["3/1/20"]
rueckmeldung-lueftungsklappen-dachfensterposition.send = "3/1/23"
Writing to devicesAuf Geräte schreiben

Every device write follows the same six steps.Jeder Schreibvorgang folgt denselben sechs Schritten.

You see what will change before anything is sent, and the previous state is saved so you can go back. An assistant edits the project. It writes a device only on a server started with --allow-programming, after your yes to its plan.Bevor etwas geschrieben wird, siehst du, was sich ändert. Der vorherige Zustand wird gesichert, damit du zurück kannst. Ein Assistent bearbeitet das Projekt. Auf ein Gerät schreibt er nur mit einem Server, der mit --allow-programming gestartet wurde, und erst nach deinem Ja zu seinem Plan.

  1. ReadLesenRead the device's tables and parameters.Tabellen und Parameter vom Gerät lesen.
  2. DiffVergleichenCompare them with your project.Mit deinem Projekt vergleichen.
  3. ConfirmBestätigenThe plan names the gateway and asks for a yes.Der Plan nennt das Gateway und fragt nach einer Bestätigung.
  4. Back upSichernSave what the device holds now to disk.Den aktuellen Stand des Geräts auf die Platte sichern.
  5. WriteSchreibenWrite the changed tables and parameters.Die geänderten Tabellen und Parameter schreiben.
  6. VerifyPrüfenRead back and compare with your project.Zurücklesen und mit deinem Projekt vergleichen.
Reading the busDen Bus lesen

One telegram, fully decoded.Ein Telegramm, vollständig decodiert.

Raw KNX telegrams carry addresses and bytes. bussard resolves both against your config, so a line in monitor reads like a sentence.Rohe KNX-Telegramme enthalten Adressen und Bytes. bussard löst beides gegen deine Konfiguration auf, sodass sich eine Zeile in monitor wie ein Satz liest.

# Windows, in PowerShell# Windows, in der PowerShell

The installers verify the checksum and put bussard on your PATH. A binary downloaded by hand needs chmod +x, and on macOS once xattr -d com.apple.quarantine, because it is not notarized. Windows shows a SmartScreen warning for the same reason.Die Installer prüfen die Prüfsumme und legen bussard in den PATH. Eine von Hand geladene Binary braucht chmod +x und auf macOS einmal xattr -d com.apple.quarantine, weil sie nicht notarisiert ist. Windows zeigt aus demselben Grund eine SmartScreen-Warnung.

You need a KNXnet/IP gateway to talk to a bus. An ETS export and vendor .knxprod files are optional but make the first minutes much nicer.Du brauchst ein KNXnet/IP-Gateway, um mit einem Bus zu sprechen. Ein ETS-Export und .knxprod-Dateien der Hersteller sind optional, machen die ersten Minuten aber deutlich angenehmer.

This is early software that writes to real building hardware. Device programming covers System B (masks 07B0, 27B0, 57B0) and System 7 (masks 0700, 0701, 0705); the device support page lists the rest. Read the safety notes before your first write, and try it on a spare device or the simulator first.Das ist frühe Software, die auf echte Gebäudetechnik schreibt. Geräteprogrammierung deckt System B (Masken 07B0, 27B0, 57B0) und System 7 (Masken 0700, 0701, 0705) ab; den Rest listet die Seite Geräteunterstützung. Lies die Sicherheitshinweise vor dem ersten Schreiben und probiere es zuerst an einem Ersatzgerät oder im Simulator aus.
