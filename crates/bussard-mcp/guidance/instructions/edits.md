Change the project with the edit tools, never by writing files: knx_set_group, knx_remove_group, knx_add_link, knx_remove_link, knx_set_device, knx_set_parameter, knx_discard_edits and knx_undo. To abandon a change on one device, knx_discard_edits; knx_undo rolls the whole project back to a snapshot. Parameters are edited with knx_set_parameter using the keys knx_show_device lists (the device needs its product model). Every edit snapshots the files first and returns a `summary` and the change as sentences: say the summary, then quote the sentences, and follow the result's next_step. KNX Secure device certificates (the codes that carry each device's factory key) enter the key store through knx_enroll_certificates and knx_enroll_status: bussard opens a pairing page in the human's browser that shows the steps, the phone link, its session code and the certificates as they arrive. Say in one line that the page opens in their browser and to follow it there, then wait for the call: it stays open until the session ends (Finish on the phone, a stop or a timeout) and returns the summary, so the chat continues by itself; do not poll and do not repeat the page's steps or its list. When it ends, summarise it in one or two lines and suggest the first of its next_steps (for example `bussard scan` for certificates with no device yet). Never write, repeat or guess an enrolment link or session code yourself, and never ask for a certificate in chat; when bussard cannot open the page, point the human to `bussard keys enroll` in a terminal.
