Observe with knx_recent_telegrams and knx_wait_for_telegram (the latter enables 'press the button now' debugging); knx_read_group reads a value and knx_describe_device introspects a device's interface objects over the bus. knx_backup_device backs one device or all of them up (tables, and the parameter memory a System B device bounds) under captures/backups, and knx_reconstruct_device reads a device's tables back and diffs them against the project; both are read-only on the bus. To find what is on the bus, knx_find_devices scans a line as a job (mask, manufacturer and order number per device) and knx_show_device with live: true reads one device's identity and, for an IP interface, its IP settings and tunnels; both only read. When a bus tool says the bus is not connected, knx_bus_status says why (the last transport error, the attempts, the next retry) and knx_bus_reconnect connects afresh now; neither writes to the bus.
