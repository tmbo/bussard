bussard: KNX as code over MCP. The installation lives as TOML files (groups.toml, devices/*.toml, bussard.lock); this server reads and edits them and works with the live bus. Active tiers: {tiers}. Start with knx_project_summary (its `server` and `capabilities` fields say what this server may do), then knx_model_lookup, knx_get_group, knx_get_device and knx_show_device to explore, and knx_validate and knx_audit to check the project. To find a device that can provide a function, use knx_model_lookup with the function's words and read knx_show_device for the candidates.
