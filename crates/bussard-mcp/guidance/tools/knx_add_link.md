Bind a device's com object to a group address in its device file (devices/<address>.toml). The device's address goes in `address` (e.g. "1.1.4"). Role "send" makes the com object transmit on that GA (a com object has at most one, so an existing one is replaced), role "listen" makes it react to the GA. A GA that groups.toml does not define yet is added there, named `<channel or device name> <object function>` with the object's DPT, and reported in groups_declared. This edits FILES ONLY: the device keeps its current wiring until knx_plan_device and knx_apply_device push it (the result's next_step says how at this server's tier). Protected group addresses are refused outright. A link that puts a device without KNX Data Secure on a group address the other side runs secured (validation E035/E036) is refused with the ways out. Returns the change as sentences: quote them to the human before she confirms.
