Back up ONE device (`address`) or every device in the project (`all: true`) over the bus, as `bussard backup` does (issue #717): reads each device's group-address and association tables and, on System B, the parameter memory the device bounds itself (PID_TABLE_REFERENCE + PID_MCB_TABLE), and writes one JSON file per device plus manifest.json under captures/backups/<timestamp>/. READ-ONLY on the bus (descriptor, authorize, property and memory reads; never a write). Returns `out_dir`, `backup` (the directory name knx_restore_tables takes), `manifest`, `devices` (per device: `status` backed_up, skipped, unreachable or failed, `file`, `mask`, `application`, `parameters` with what was captured or why not, `detail`, `identity`) and `totals`. A device that is switched off is `unreachable`, not a failure; `ok` is false only when a device answered and its read failed. Suggest it before a change the human may want to undo. Backing up every device takes a few seconds per device. Only available when the server is NOT in passive mode.
