Drop the bus connection and connect afresh now: a new socket, a new KNXnet/IP Secure session and the reconnect backoff reset. A connected bus closes its tunnel cleanly first. Not a write: nothing is sent on the KNX bus, only the connection to the interface is rebuilt. Returns the bus status after the attempt (knx_bus_status's fields). Use it when knx_bus_status shows the bus stuck reconnecting.
