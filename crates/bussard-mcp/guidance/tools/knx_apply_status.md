Report one job of the programming tier (issues #289, #332): an apply started by knx_apply_device or knx_restore_parameters, or a plan started by knx_plan_device (`kind`: apply or plan). `state` (running, done, or interrupted when the server stopped mid-write), `done`, the current `step`, `progress` (the table outcome, the download step, the segment position, the octets the last segment wrote of those it may write), the backup paths and, once done, `result`: the same result knx_apply_device returns inline (ok, verified, parameters, recovery), or for a plan job the plan exactly as knx_plan_device returns it (sentences, question, plan_digest).
