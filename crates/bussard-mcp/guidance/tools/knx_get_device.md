Get the full definition of one device by its address: identity, product, location, channels, its parameters (by the keys the device file uses) and generated com-object table, plus every link (com-object -> group addresses) on it. ETS-internal values the user cannot set are left out and counted in `hidden_parameters`; `technical: true` includes them. Outputs of a <ParameterCalculation> that the configuration computes are listed in `computed_parameters` (key, the value a download writes, `computed_by`: the calculation id); they are not set in the file. This is the configured state; for what the device can do (inactive channels and pages, functions, choices) use knx_show_device.
