Import a file from ETS or a vendor into the project, as `bussard import`, `bussard import-product` and `bussard keys import` do, chosen by the file type: a .knxproj (ETS project export) or .bussard bundle is written into the project (a re-import keeps hand-edited names, rooms and descriptions and lists each one that differs; pass theirs: true to take the incoming values); a .knxprod is stored as product data and its product models generated; a .knxkeys is merged into the key store bussard.keys. Vendor product data by order number: {order_number, download: true}. Downloading copyrighted vendor data needs the human's consent: ask, then pass download: true (never `yes`); without it nothing is downloaded and the result says what would be. A protected .knxproj the server has no password for: when the chat app shows links, bussard shows the human its own password form on this computer, stores the password in .env and imports; never ask for it in chat. Otherwise the result asks for `password`. A .knxkeys needs `password` (ask the human; it is never echoed or stored) unless the server's environment has it. Run knx_diff_project first and quote its sentences before importing a project or bundle. Snapshots the project first (knx_undo puts it back); touches no device. Returns sentences: quote the summary.
