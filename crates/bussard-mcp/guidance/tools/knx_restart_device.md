Restart ONE device on the PHYSICAL bus in the form ETS uses for it and wait until it answers again, as `bussard restart <address>` does (issue #717), in two calls. Without plan_digest: sends nothing and returns `form` ("confirmed", the master reset a System B application that supports Secure answers, or "basic", a bare A_Restart), `form_reason`, the `question` and a plan_digest. Tell the human the device restarts and ask the question. With the plan_digest (ONLY after the human's explicit yes in this conversation): restarts as a job like knx_apply_device (`started: true` with a `job`: poll knx_apply_status). The result says `confirmed` (the device answered the restart with error code 0; a basic restart is never confirmed, only seen to answer again), `mask` and `answered_after_ms`; `ok: false` with the reason when a confirmed restart is refused or the device does not come back. Only available with --allow-programming.
