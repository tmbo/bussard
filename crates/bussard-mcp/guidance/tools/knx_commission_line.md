Commission a LINE on the PHYSICAL bus, the flow of `bussard commission` (issue #753): give each device the project has on the line its address, one press of a programming button at a time, and return the label text per device. Three kinds of call. (1) `line` alone (e.g. "1.1") reads the project only and returns the devices by name, room and order number, `sentences`, `question` and `plan_digest`: show the sentences and ask the question. (2) ONLY after the human's explicit yes in this conversation, call again with `line`, `plan_digest` and `yes: true`: it starts a job (poll knx_job_status). The job skips the devices that already answer at their address, then repeats per device: `press_button` (`question` names the device by name, room and order number: relay it word for word; the job waits up to 30 s), `identified` (serial, mask and order number read at the device's current address, the order number checked against the project) and `assigned` (the address written and read back at the new address; `progress.devices` gets the device's report and `label`). That one yes covers every device whose identification matches the project's order number, exactly as the CLI's one confirmation covers its run: no further yes per device. Anything else pauses the job with `waiting` (reason) and `question`, writing nothing: another product, an unreadable order number, no device or several in programming mode, or a device the project has no order number for. (3) Pass the human's word as `job` with `answer`: "retry", "skip" or "stop", or "assign" where the question offers it (a device the project has no order number for). The human can stop the run at any time: `answer: "stop"` ends it at once while it waits for a button, else after the device it is on. The result has `devices` (status, identified, readback, label), `labels`, the totals, `not_reached` and `summary`. Only addresses are written, as `bussard commission` without --flash/--apply: push each device afterwards with knx_plan_device and knx_apply_device. Securing a fresh device stays with ETS. Only available with --allow-programming.
