Open the project in a web browser: starts the page `bussard viz` serves (devices, group addresses, links and live telegrams) inside this server and returns its `url`. Give the human the url to open; it works only in a browser on this computer. The page is read-only: it never writes to the bus, and its live telegrams are the ones this server already receives, without a second bus connection. A second call returns the same url; the page stops when the server stops.
