Change one device parameter value in its device file, devices/<address>.toml (e.g. a night setback temperature). `parameter` is the key knx_show_device lists (`helligkeitsschwelle`, page-qualified `sollwerte.komfort`, or `key@reference`); the same key prefixed with its page or channel handle (`universalkanal-c4-funktion.helligkeitsschwelle`) and the bare reference (`P-7305_R-7305`) work too, and `channel` takes a channel handle, `device` or a page handle, as knx_show_device does, when the key repeats. An unknown key is refused with the three closest keys on the device. Any parameter the lock knows for the device, or the product model's pages hold (one on a page that was inactive at import), can be set, and the value (an enum label or code, a number) is checked against the vendor's product model first; without a product model the edit is refused rather than guessed. This edits FILES ONLY: the device keeps its current settings until the change is pushed with knx_plan_device and knx_apply_device (the plan lists the parameter by name); the result's next_step says how it reaches the device at this server's tier. Parameters at their vendor default are set the same way. A parameter that shows or hides com-objects (an enable flag, a data length) changes the group-object table, which only a full download writes: the result's `note` names the objects and how that download is pushed at this server's tier (with --allow-programming, knx_plan_device plans it as `method: flash`), and knx_show_device lists the parameters and objects it reveals right away. A parameter the configuration does not show under the device's current values (its page is inactive, or it belongs to another branch of a choice) is refused with the condition that shows it and the ref that is shown instead, because the device would never get the value; `force: true` stores it anyway to prepare a branch before switching to it. A bare parameter id (`P-7305`) or the vendor text names the ref the configuration shows. An output of a <ParameterCalculation> is refused, also with `force`: ETS shows it read-only and a download writes what the calculation computes, so set the inputs the refusal names; the change then lists the output's new computed value. Returns the change as sentences and a `summary`: say the summary to the human, then quote the sentences.
