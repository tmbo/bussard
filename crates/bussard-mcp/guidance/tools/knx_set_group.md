Create or update a group address in groups.toml: its name, datapoint type and free-text note. Creating one needs a name. This edits FILES ONLY: no telegram is sent, and no device stores a group address's name or type; links that use it are pushed per device with knx_plan_device and knx_apply_device. A group address marked protected (safety-critical, e.g. a wind alarm) cannot be renamed or retyped here, and there is deliberately no way to set or clear that flag over MCP. `secure` switches KNX Data Secure for the group address: false removes its group key from the key store (bussard.keys) and clears the secure flag of the group and of every linked com-object on every device, true sets them and generates a group key when the store has none; one change, undone with knx_undo. The Secure devices linked to it then need knx_plan_device and knx_apply_device (their security object changes), and Home Assistant and every other user of an exported keyring need a new `bussard keys export`. Returns the change as sentences and a `summary`: say the summary to the human, then quote the sentences.
