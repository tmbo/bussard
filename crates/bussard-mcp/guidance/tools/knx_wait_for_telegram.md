Block until the next telegram matching the given group address and/or source arrives, or the timeout elapses. This is the 'ask the human to press the button now, then call this' workflow: tell the user which switch to press, then call this and read the resulting telegram. A timeout is a normal result (not an error). With the server's --keyring, a secured (KNX Data Secure) group telegram arrives decrypted and carries secured: true; one the server has no group key for keeps its ciphertext with secure_status no_key.
