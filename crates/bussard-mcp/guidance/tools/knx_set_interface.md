Edit the [knxnet] table of a KNX IP interface's device file (devices/<address>.toml): how it gets its IP address (assignment `dhcp` or `static`, with ip_address, netmask and default_gateway for static), its friendly name, and its tunnelling addresses (tunnels replaces the list; add_tunnels and remove_tunnels change it). Pass only what changes. The table is validated before it is saved: a static assignment needs an address and a netmask, static settings under dhcp, a friendly name over 30 ISO 8859-1 characters, a tunnel address listed twice, off the interface's line or used by a device of the project are refused (E043 to E046), and the result's `warnings` carry W047 when the tunnels differ from the ones the server's keys list for the interface. The device must already have a [knxnet] table (import and adopt write it). This edits FILES ONLY: knx_plan_device shows the property writes and knx_apply_device writes them to the interface's KNXnet/IP parameter object; a change of the IP assignment, address or tunnel addresses of the interface this server tunnels through is refused there (the owner applies it with `bussard apply <address> --allow-self-reconfigure`). Returns the change as sentences and a `summary`: say the summary to the human, then quote the sentences.
