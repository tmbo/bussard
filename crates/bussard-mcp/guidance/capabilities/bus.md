This server reads the project files, observes the bus, reads group values (knx_read_group), introspects devices (knx_describe_device), backs devices up (knx_backup_device), reads a device's tables back against the project (knx_reconstruct_device), finds the devices on a line (knx_find_devices) and reads one device's live status (knx_show_device with live: true). It reports the bus connection (knx_bus_status) and rebuilds it on request (knx_bus_reconnect).
