- Hidden parameters are written at their defaults only by a System B program that
  does not declare `DownloadInvisibleParameters`, as ETS does (#448); a System 7
  program keeps the segment template for them, and
  `PreferPartialDownloadIfApplicationLoaded` no longer decides it. The Steinel
  HPD 2 and TruePresence, ekinex, B.E.G. DIM, Zennio Sensato, Elsner and
  Busch-Jaeger `A-FF11-15` images no longer carry hidden defaults, and the
  Busch-Jaeger fan coil and valve drive controllers now do.
