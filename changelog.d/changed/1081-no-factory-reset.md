- Flash: a System B download of an application that supports Secure and writes a filled segment sparsely no longer opens with a factory reset (`A_Restart` master reset, erase code 7), as ETS sends none on a fresh or a programmed device. The allocation with the fill flag has the device fill the segment, so no octet of an earlier image survives. The device now keeps what that reset cleared and ETS keeps: its access keys, the data the application stores outside the download, and on a Data Secure device its group and point-to-point keys and security address table until the download rewrites them. The reset stays for a `--force` over another application or an unreadable one, and a load procedure's own `LdCtrlMasterReset` is sent as before. Such a download is one reset and one reconnect shorter, and a re-flash of the same application can skip objects whose image already matches, as for every other product (#1081).
