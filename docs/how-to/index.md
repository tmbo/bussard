# How-to guides

Every guide shows each step in two forms, "In chat" with an assistant and "At the terminal", and the tab you pick stays picked on every page. Each guide answers one question; pick the task.

| I want to ... | Guide |
|---|---|
| see what is happening on the bus, read a value, watch it in a browser | [Watch the bus](watch-the-bus.md) |
| know what devices and group addresses I have | [Find what you have](find-what-you-have.md) |
| make a button do something else, and undo it | [Change what a button does](change-a-link.md) |
| change a run time, a mode, a threshold on a device | [Change a parameter](change-a-parameter.md) |
| put a new device on the bus, with or without an ETS project | [Add a device](add-a-device.md) |
| keep a backup, bring a dead device back | [Back up and replace](back-up-and-replace.md) |
| plan and commission a whole line, run an acceptance test | [Commission a line](commission-a-line.md) |
| get my names into ETS, see what a new ETS export changes | [Exchange with ETS](exchange-with-ets.md) |
| send changes to an integrator and get them back | [Work with an integrator](work-with-an-integrator.md) |
| drive the house from Home Assistant | [Home Assistant](home-assistant.md) |
| use keyrings, secure interfaces and secured group addresses | [KNX Secure](knx-secure.md) |

Before the first guide that writes to the bus, read [Safety](../explanation/safety.md) once.
